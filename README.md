# Кадр

Учебное Android-приложение для кинотеатра. В нём можно выбрать сеанс и места, посмотреть на экран из кресла в 3D и оформить демонстрационный билет. Данные хранятся на устройстве в Room.

**Автор** — Ильин Вячеслав Владимирович  
**Группа** — П-311-3К

## Возможности

- Афиша с постерами и фильтрами по дате и формату.
- Схема мест с доступностью и категорией «Комфорт».
- 3D-просмотр залов IMAX, VIP и 2D из выбранного кресла с полноэкранным режимом.
- Оформление билетов и бронирование мест, расчёт скидок и бонусов.
- Личный кабинет с историей билетов и бонусным балансом.
- Локальный кабинет сотрудника. Администратор приложения управляет кинотеатрами и сотрудниками, администратор кинотеатра — фильмами, залами, сеансами и отчётами, контролёр проверяет QR-коды билетов на этом же устройстве.

## Запуск

1. Откройте папку `android/` в Android Studio и дождитесь синхронизации Gradle.
2. Выберите конфигурацию `app` и устройство с Android 8.0 или новее. Нажмите **Run**.
3. При первом запуске приложение заполнит Room встроенным каталогом, залами, схемами мест и расписанием.
4. Для покупки зарегистрируйте локального зрителя. Для кабинета сотрудника откройте «Вход», заполните поля и выберите создание локального администратора. Он сможет создавать учётные записи сотрудников.

В тестовой оплате деньги не списываются. Покупки, изменения каталога и учётные записи доступны после перезапуска приложения на том же устройстве.

Для сборки APK выполните задачу Gradle `:app:assembleDebug`. Файл появится в `android/app/build/outputs/apk/debug/`.

## Проверка

На запущенном эмуляторе выполните задачу Gradle `:app:connectedDebugAndroidTest`. Тесты проверяют оформление и сохранение билета, а также переход со схемы Room 1 на 2.
