# Кадр

Учебное мобильное приложение для покупки билетов в кинотеатр с выбором мест и 3D-просмотром зала. Веб-часть обслуживает рабочий кабинет сотрудников.

**Автор** — Ильин Вячеслав Владимирович  
**Группа** — П-311-3К

## Возможности

- Афиша с постерами и фильтрами по дате и формату сеанса.
- Выбор мест на схеме зала с отображением занятых мест и категории «Комфорт».
- 3D-вид из выбранного кресла с поворотом камеры и полноэкранным режимом.
- Оформление билетов с расчётом стоимости и учётом бонусов.
- Личный кабинет зрителя с билетами и бонусным балансом.
- Кабинет сотрудника с тремя ролями. Администратор приложения управляет кинотеатрами и сотрудниками, администратор кинотеатра — фильмами, сеансами, ценами и отчётами, контролёр проверяет билеты.

| Android | Kotlin, Jetpack Compose, Retrofit + Gson, WebView с WebGL 2 |

| Инструменты | Android Studio, Git |

## Запуск

### Сервер через Docker

1. Установите Docker с Docker Compose.
2. Скопируйте [`.env.example`](deploy/.env.example) в `deploy/.env` и задайте собственные значения переменных базы данных. Храните этот файл локально.

   | Переменная | Назначение |
   | --- | --- |
   | `DB_PASSWORD` | Пароль пользователя MySQL, через которого API подключается к базе |
   | `DB_ROOT_PASSWORD` | Пароль учётной записи MySQL с правами администратора |
   | `KADR_ADMIN_PASSWORD` | Пароль для первоначального создания учётной записи администратора с логином `admin` |
   | `PUBLIC_HOST` | Адрес для Caddy. Значение `:80` в шаблоне включает HTTP для локального запуска |

   Если нужен кабинет сотрудника, задайте `KADR_ADMIN_PASSWORD` перед первым запуском. Администратор приложения сможет создать учётные записи сотрудников.

3. Из корня репозитория выполните команду.

   ```bash
   docker compose --env-file deploy/.env -f deploy/docker-compose.yml up -d --build
   ```

4. После запуска MySQL и API откройте `http://localhost/api/health` и убедитесь, что в ответе есть `"ok": true`.

### Сборка в Android Studio

1. Откройте папку `android/` в Android Studio и дождитесь синхронизации Gradle. Установите предложенные компоненты Android SDK, если IDE их запросит.
2. Запустите эмулятор. Чтобы подключить его к локальному серверу, выполните команду из Android SDK Platform-Tools.

   ```bash
   adb reverse tcp:8000 tcp:80
   ```

3. Укажите адрес API в `android/gradle.properties`. При подключении через `adb reverse` используйте значение из примера.

   ```properties
   kadr.serverUrl=http://localhost:8000/
   ```

4. Выберите конфигурацию `app` и нажмите **Run**. Для отдельного APK выполните задачу Gradle `:app:assembleDebug`. Готовый файл появится в `android/app/build/outputs/apk/debug/`.
